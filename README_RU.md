# CasinoCraft 1.1 — Fabric 1.20.1

## Состав версии
- Казино-проверки на добычу блоков, еду, атаки и взаимодействия с блоками.
- Базовый шанс выигрыша 60%, который уменьшается по мере роста зависимости.
- Шкала зависимости 0–100 и долги казино (пока хранятся в памяти сервера до перезапуска).
- Проигрыши накладывают случайные дебаффы; на высокой зависимости наказания становятся тяжелее.
- Награды: опыт, насыщение, эффект удачи и жетоны казино.
- Зарегистрированы блоки «Игровой автомат» и «Стол рулетки» как строительные блоки-заготовки.
- Команды: `/casino help`, `/casino play`, `/casino status`, `/casino roulette <0-36>`, `/casino repay <amount>`, `/casino quest`.

## Сборка
Нужны Minecraft Java 1.20.1, Java 17, Fabric Loader и Fabric API.
В папке проекта выполни `gradle build`. JAR будет в `build/libs/`.

## Ограничения прототипа
Это расширенный исходный прототип, а не финальная отполированная версия:
- GUI, анимации игровых автоматов и интерактивный стол рулетки ещё не сделаны.
- Долги и зависимость пока хранятся в оперативной памяти и сбрасываются при перезапуске сервера.
- Квестовая цепочка пока является заготовкой с ручными этапами.
- Игровые блоки пока зарегистрированы, но их собственное меню и логика ещё впереди.
- Не все действия Minecraft перехвачены; текущие события перечислены выше.
- Перед релизом проект нужно собрать и проверить на конкретной установке Fabric.
